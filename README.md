# 🌍 AI Language Translation Tool

An AI-powered multilingual language translation tool built with Python and Streamlit. The application translates text between multiple languages and also provides text-to-speech functionality for the translated text.

## 🚀 Live Demo

https://codealpha-language-translationtool.streamlit.app//

## ✨ Features

- 🌐 Supports multiple languages
- 🔄 Real-time text translation
- 🔊 Text-to-speech for translated text
- 📝 Simple and user-friendly interface
- ⚡ Fast translation
- 📱 Accessible through a web browser

## 🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- Google Translator
- gTTS (Google Text-to-Speech)

## 🌍 Supported Languages

- English
- Hindi
- Telugu
- Tamil
- Kannada
- Marathi
- Bengali
- Gujarati
- French
- German
- Spanish
- Japanese
- Chinese
- Korean
- Arabic

## ⚙️ How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click the **Translate** button.
5. The translated text is displayed.
6. Use the audio player to listen to the translation.
