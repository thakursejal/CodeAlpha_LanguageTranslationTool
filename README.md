# 🌍 AI Language Translation Tool

> **Translate. Communicate. Connect. 🤝**

An AI-powered **Language Translation Web Application** built using **Python and Streamlit**. The application translates text between multiple languages and provides **text-to-speech output** for the translated text.

## 🚀 Live Demo

🔗 **[Try the AI Language Translation Tool](https://codealpha-language-translationtool.streamlit.app/)**

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔄 Real-time text translation
- 🔊 Text-to-speech for translated text
- 📝 Simple and interactive interface
- ⚡ Fast translation
- 📱 Accessible through a web browser
- 🌍 Supports Indian and international languages

## 🧠 How It Works

**Enter Text**  
↓  
**Select Source & Target Languages**  
↓  
**Translation API**  
↓  
**Translated Text**  
↓  
**Text-to-Speech 🔊**  
↓  
**Audio Output**

## ⚙️ How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click the **Translate** button.
5. The translated text is displayed.
6. Use the audio player to listen to the translated text.
